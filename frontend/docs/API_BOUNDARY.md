# 旧版 Web API 边界

本仓库不包含旧版 API 源码，也不验证最新版 API。

浏览器生产请求的 API origin 不写死在仓库里，由构建期环境变量指定：

    RPT_PROXY_BASE=<你的部署 origin>   # 例如 https://your.host
    未设置时构建产物默认使用 http://127.0.0.1:3200/legacy-api

旧版上传文件公开路径为：

    /legacy-uploads

以下后端路由契约测试不属于 Web 仓库，必须在独立的旧版 API 仓库维护并与 Web 发布标签关联：

- 内容发布与角色路由；
- 双端聊天路由；
- 补件与还款计划路由。

Web 发布前需要验证登录、报告恢复、报告上传以及上传结果 URL 均保持在上述旧版命名空间内。
