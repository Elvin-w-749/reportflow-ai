本协议是你与本服务运营主体之间关于使用本服务用户端、老师端、监控端及相关云端服务所订立的协议。你注册、登录、上传材料、查看信用报告分析、发起咨询或继续使用本服务，即表示你已阅读并同意本协议。

如你不同意本协议，请停止注册或使用相关服务。

## 二、服务内容

本服务可能提供以下服务：

1. 信用报告上传、解析、管理、重传、删除。
2. 信用画像总览、账户明细、查询记录、负债结构、风险命中、评分参考和优化建议展示。
3. 顾问咨询、老师端协同、监控端质检、任务跟进和消息提醒。
4. 异议管理、修复进度、证据材料整理和执行建议。
5. 与上述服务相关的账号、客服、安全、日志和数据同步能力。

具体功能以实际页面展示为准。我们可能根据产品规划、合规要求或运营安排调整、暂停或下线部分功能。

1. 你承诺上传的信用报告、图片、PDF、证据材料、咨询内容等均来源合法，属于你本人或你已获得合法、充分、有效授权。

2. AI 或规则分析可能存在识别错误、字段缺失、格式兼容、扫描质量、数据过期等问题。你应以原始报告和金融机构实际反馈为准。
3. 本服务不承诺贷款审批通过、不承诺信用修复成功、不承诺降低债务、不承诺任何金融产品收益。
4. 涉及贷款、债务重组、法律争议、征信异议等重大事项时，应结合专业机构或专业人士意见审慎决策。

1. 在用户授权和服务必要范围内，老师端/监控端可以读取云端同步后的报告摘要、账户明细、风险命中、任务进度和咨询记录。
2. 老师端/监控端不应越权读取用户本地文件、未同步缓存或与服务无关的数据。
3. 顾问意见属于服务建议，不构成金融机构审批意见、法律意见或强制性处理方案。
